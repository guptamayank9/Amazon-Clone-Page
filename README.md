# 🛒 Amazon Clone Website

A fully responsive **Amazon Clone Website** built using **HTML and CSS**, designed to replicate the look and feel of the original Amazon homepage. This project focuses on frontend development skills such as layout design, responsiveness, and UI structuring.

---

## 🚀 Live Demo

🔗 https://guptamayank9.github.io/Amazon-Clone-Page/

---

## 📌 Features

* 🧭 Amazon-like **Navigation Bar**
* 🔍 Functional **Search Bar UI**
* 🛍️ Product listing in **grid layout**
* 🖼️ Hero section with banner image
* 📦 Multiple product categories
* 📱 **Responsive Design** (mobile-friendly)
* 🔗 Footer with useful links

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* Flexbox & Grid
